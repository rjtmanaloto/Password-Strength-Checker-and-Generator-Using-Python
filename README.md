<h1>Password Strength Checker and Generator Using Python</h1>


<h2>Goal</h2>

Create a simple desktop application that evaluates password strength, identifies weaknesses, and generates random passwords.

<h2>Objectives</h2>

1. Check whether a password contains at least 1 uppercase letter, 1 lowercase letter, 1 number, 1 symbol, and at least 8 characters.
2. Calculate a password score from 0 to 5 based on the requirements.
3. Classify the password as Weak, Fair, Good, or Excellent.
4. Display specific feedback identifying which password requirements are missing.
5. Allow users to show or hide the password.
5. Allow users to generate random passwords between 4 and 32 characters. 
6. Ensure generated passwords contain at least 1 uppercase letter, 1 lowercase letter, 1 number, and 1 symbol.

<h2>Features</h2>

- <b>Password Strength Checker:</b>
    1. Password Input Field: A text input field where users can enter their password and where generated passwords are displayed.
    2. Show / Hide Button: Allow users to show or hide the entered or generated password.
    3. Check Password Button: Analyzes the user's password and evaluates its strength.
    4. Score and Progress Bar: Displays the password score from 0 to 5 using a numerical score and a visual progress bar.
    5. Feedback System: Displays the password's strength and identifies which requirements are missing.
- <b>Password Generator:</b>
    1. Password Length Slider: Allows users to adjust the generated password length between 4 and 32 characters.
    2. Generate Password Button: Generates a random password containing at least 1 uppercase letter, 1 lowercase letter, 1 number, and 1 symbol. 

<h2>Tools Used</h2>

- <b>Visual Studio Code</b>
- <b>Python 3.13</b>
- <b>CustomTkinter</b> 

<h2>Environments Used</h2>

- <b>Windows 11</b>
